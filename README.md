# Hexuan Yu — Academic Homepage

This is the source repository for Hexuan Yu's academic personal homepage, built with [Jekyll](https://jekyllrb.com/) and based on the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme by Yaoyao Liu.

## Structure

- `index.md` — homepage content (About Me, Research Interests, News, Professional Service)
- `_includes/profile.html` — profile sidebar (name, contact, social links)
- `_includes/publications.md` — publications list template
- `_data/publications.yml` — publication entries
- `_config.yml` — site configuration
- `_sass/` — stylesheets
- `assets/` — images, fonts, and scripts

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then view the site at <http://localhost:4000>.
